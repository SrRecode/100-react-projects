# Day 13: Build notebook app using react

> Project 13 of 100 · Folder: `day-13-build-notebook-app-using-react`

## What it does

Write and organize multiple notes.

### Included workflow

Create, search, edit/autosave, pin, export as Markdown, and delete notes.

### Scope and limitations

Notes use localStorage and are not encrypted or synchronized.

## Run locally

Use Node.js 20.19+ or 22.12+ and npm. From this folder:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually <http://localhost:5173>). To make and preview a production build:

```sh
npm run build
npm run preview
```

### Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run preview` — `vite preview`

## Implementation

- **Framework:** React with Vite.
