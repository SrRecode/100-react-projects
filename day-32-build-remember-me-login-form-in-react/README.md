# Day 32: Build Remember Me Login Form in React

> Project 32 of 100 · Folder: `day-32-build-remember-me-login-form-in-react`

## What it does

Preview a role-aware sign-in screen.

### Main workspace

Choose a demo role, enter a sample email, and preview local sign-in.

### Hands-on workbench

Enter a sample email, choose a role, preview the signed-in state, and sign out.

### Scope and limitations

No password, identity provider, server session, or real authorization. No password, provider, server session, or real authorization.

## Run locally

Use Node.js 20.19+ or 22.12+ and npm. From this folder:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually <http://localhost:5173>). To make and preview a production build:

```sh
npm run build
npm run preview
```

### Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run preview` — `vite preview`
