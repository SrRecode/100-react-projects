# Day 79: Build React Multiple Image to PDF

> Project 79 of 100 · Folder: `day-79-build-react-multiple-image-to-pdf`

## What it does

Create a multi-page PDF from images.

### Main workspace

Choose one local file (up to 25 MB), inspect details, and preview it if it is an image.

### Hands-on workbench

Choose ordered images, remove selections, and export one image per page.

### Scope and limitations

Generated locally; large inputs can use significant memory. File is not uploaded; the generic selection is temporary.

## Run locally

Use Node.js 20.19+ or 22.12+ and npm. From this folder:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually <http://localhost:5173>). To make and preview a production build:

```sh
npm run build
npm run preview
```

### Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run preview` — `vite preview`

## Implementation

- **Framework:** React with Vite.
- **Entry point:** `src/main.jsx` loads `src/App.jsx`.
- **Feature files:** `src/App.jsx`, `src/FeatureLab.jsx`, `project.json`, and their styles.
- **Runtime dependencies:** `react`, `react-dom`, `vite`, `jspdf`.
- **Development dependencies:** none listed.
- **Data:** The shared shell uses browser localStorage; workbench data may be in page memory or IndexedDB, as noted above.
