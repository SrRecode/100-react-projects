# Day 91: Generate Image from Video Frames

> Project 91 of 100 · Folder: `day-91-generate-image-from-video-frames`

## What it does

Capture a frame from a local video.

### Main workspace

Generate a random hex-color variation, then copy or download it.

### Hands-on workbench

Choose a video, seek with native controls, and save the current frame as PNG.

### Scope and limitations

Local canvas capture; codec and browser API support vary. This shared panel is a random-color sample, not a connected AI/API generator.

## Run locally

Use Node.js 20.19+ or 22.12+ and npm. From this folder:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually <http://localhost:5173>). To make and preview a production build:

```sh
npm run build
npm run preview
```

### Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run preview` — `vite preview`
