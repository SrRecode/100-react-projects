# Day 94: React Intersection Observer

> Project 94 of 100 · Folder: `day-94-react-intersection-observer`

## What it does

Observe sample tiles entering a scroll frame.

### Main workspace

Add, search, complete/reopen, remove, and JSON-export simple sample entries.

### Hands-on workbench

Scroll the sample list and inspect in-view/out-of-view states.

### Scope and limitations

Uses IntersectionObserver; unsupported browsers display the fallback. Records are browser-local. The generic record is a label/status; topic-specific fields are not implied.

## Run locally

Use Node.js 20.19+ or 22.12+ and npm. From this folder:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually <http://localhost:5173>). To make and preview a production build:

```sh
npm run build
npm run preview
```

### Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run preview` — `vite preview`
