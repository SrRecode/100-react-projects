# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React with Vite (existing project)

## Users

Frontend developers creating animated CSS backgrounds.

## Product Purpose

Help frontend developers create and preview animated gradients, then use the generated CSS in their projects.

## Positioning

Open decision: the product's distinctive mechanism beyond live gradient preview and CSS generation.

## Capabilities and Constraints

Provides a live animated preview for linear, radial, and conic CSS gradients, editable color stops and positions, direction and speed controls, starter presets, a randomize action, pause/play, and copyable CSS. Visitors can save and restore named studies in local browser storage. Honors the visitor's reduced-motion preference.

## Evidence on Hand

No customer evidence or product assets were supplied. Do not invent endorsements or performance claims.

## Product Principles

- Make the gradient visible while it is being edited.
- Keep generated CSS close to the preview and easy to reuse.
- Let developers adjust the output rather than hiding its implementation.
