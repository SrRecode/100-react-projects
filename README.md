# 100 React projects

A collection of 100 independently runnable React projects based on the supplied playlist. Each numbered `day-NN-*` folder is a separate Vite application; `gradient-generator` is Day 1.

## Run one project

From its folder:

```sh
npm install
npm run dev
```

Build it with `npm run build`. Every app is client-side and stores demo data in local browser storage where applicable. Sign-in and checkout flows are demonstrations only; no credentials or payment information are sent to a service.

## Run the collection

From this directory:

```sh
npm install
npm run build:apps
```

## Privacy and setup

Provider-backed identity, APIs, payments, camera, microphone, and notification features require their real services or explicit browser permissions. This collection uses local/demo behavior by default and never ships secrets or charges a payment method.
