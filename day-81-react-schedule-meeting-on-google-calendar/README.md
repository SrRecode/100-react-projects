# Day 81: React Schedule Meeting On Google Calendar

> Project 81 of 100 · Folder: `day-81-react-schedule-meeting-on-google-calendar`

## What it does

Create a calendar invite file.

### Main workspace

Add, search, complete/reopen, remove, and JSON-export simple sample entries.

### Hands-on workbench

Enter a meeting title/start time and download a one-hour .ics event.

### Scope and limitations

No Google Calendar API/account integration; import the file yourself. Records are browser-local. The generic record is a label/status; topic-specific fields are not implied.

## Run locally

Use Node.js 20.19+ or 22.12+ and npm. From this folder:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually <http://localhost:5173>). To make and preview a production build:

```sh
npm run build
npm run preview
```

### Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run preview` — `vite preview`

## Implementation
