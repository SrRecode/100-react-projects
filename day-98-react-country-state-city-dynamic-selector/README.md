# Day 98: React Country State City Dynamic Selector

> Project 98 of 100 · Folder: `day-98-react-country-state-city-dynamic-selector`

## What it does

Choose a country, region, and city from sample data.

### Main workspace

Search seeded entries and inspect matching local results.

### Hands-on workbench

Select Pakistan, India, or Canada, then choose an available region and city.

### Scope and limitations

Small hard-coded list; production needs a maintained location dataset. No remote index or production search service.

## Run locally

Use Node.js 20.19+ or 22.12+ and npm. From this folder:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually <http://localhost:5173>). To make and preview a production build:

```sh
npm run build
npm run preview
```

### Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run preview` — `vite preview`

## Implementation

- **Framework:** React with Vite.
- **Entry point:** `src/main.jsx` loads `src/App.jsx`.
- **Feature files:** `src/App.jsx`, `src/FeatureLab.jsx`, `project.json`, and their styles.
- **Runtime dependencies:** `react`, `react-dom`, `vite`.
- **Development dependencies:** none listed.
- **Data:** The shared shell uses browser localStorage; workbench data may be in page memory or IndexedDB, as noted above.

Only grant browser permissions when you choose to use the relevant feature. Treat sample data as disposable.
