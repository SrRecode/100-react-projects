# Day 50: Changing user roles to Admin

> Project 50 of 100 · Folder: `day-50-changing-user-roles-to-admin`

## What it does

Preview a local role-change interaction.

### Main workspace

Choose a demo role, enter a sample email, and preview local sign-in.

### Scope and limitations

No user record is updated and no action is server-authorized. No password, provider, server session, or real authorization.

## Run locally

Use Node.js 20.19+ or 22.12+ and npm. From this folder:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually <http://localhost:5173>). To make and preview a production build:

```sh
npm run build
npm run preview
```

### Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run preview` — `vite preview`
